**Interfacing Arduino UNO and I2C to Demonstrate Pulse Amplitude Modulation**

This project demonstrates Pulse Amplitude Modulation (PAM), a basic modulation technique. An Arduino UNO communicating over I2C converts a digital signal to analog, and the amplitude of the output pulses carries the information. AC coupling with a non-polarized capacitor removes the DC offset, which converts the unipolar signal into a bipolar one.
